# 南京晓庄 2026 学生手册自动作答助手

一个用于南京晓庄学院2026年学生手册模拟考试的 JavaScript 用户脚本。当前脚本版本为 **1.2.0**。

**仅适用于 [南京晓庄学院2026年学生手册模拟考试](https://ks.wjx.com/vm/mHriy8I.aspx) 这个网页，与正式考试不通用。**

## 功能

- 在浏览器本地保存姓名、学院、学号，刷新后先填写基本信息，再自动作答。
- 内置题库，按题干、题型及选项文本匹配答案，支持选项顺序变化。
- 未找到可用题库答案时，单选题随机选择一个选项，多选题选择全部选项。
- 浮窗显示题库命中、随机/全选及异常情况，支持暂停、继续和重填本页。
- 浮窗支持拖动、折叠。
- 不自动提交，检查结果后需自行提交。

## 安装与使用

1. 在浏览器安装 Tampermonkey 等兼容用户脚本的扩展。
2. [点击下载/安装](https://raw.githubusercontent.com/DreamYuande/njxzc-handbook-2026-helper/main/%E5%8D%97%E4%BA%AC%E6%99%93%E5%BA%842026%E5%AD%A6%E7%94%9F%E6%89%8B%E5%86%8C%E8%87%AA%E5%8A%A8%E4%BD%9C%E7%AD%94%E5%8A%A9%E6%89%8B.user.js)，在用户脚本扩展的提示中确认安装或更新。
3. 打开 [南京晓庄学院2026年学生手册模拟考试](https://ks.wjx.com/vm/mHriy8I.aspx) 页面。
4. 在右下角助手的“基本信息设置”中填写姓名、学号并选择学院，点击“保存信息”。
5. 刷新网页，脚本将读取已保存信息并开始填写、作答。
6. 检查基本信息、随机/全选及异常详情，按需手动修改答案，最后自行提交。

修改基本信息后，也需要保存并刷新页面。已经处理的题目不会反复覆盖手动调整；点击“重填本页”会再次应用脚本的选择规则。

## 适用范围与数据

- 仅适用于 [南京晓庄学院2026年学生手册模拟考试](https://ks.wjx.com/vm/mHriy8I.aspx) 这个网页，**与正式考试不通用，也不适用于其他问卷或考试页面**。当前脚本的 `@match` 为 `https://ks.wjx.com/vm/mHriy8I.aspx*`。
- 学院可在助手中选择，选项直接读取当前问卷的学院列表。已保存的姓名、学号和学院会保留；修改学院后请保存并刷新页面。
- 姓名、学院、学号保存在当前问卷页面所属站点的 `localStorage` 中，键为 `njxzc.handbook.profile.v1`。脚本没有额外的网络请求或数据上传逻辑；这些信息会被填写到问卷中。
- 内置题库包含待确认答案。随机单选及多选全选属于兜底选择，不能视作正确答案。
- 网页结构、选项或规则变化可能影响脚本运行。

## 本地检查

可使用 Node.js 检查 JavaScript 语法：

```sh
node --check "南京晓庄2026学生手册自动作答助手.user.js"
```

此检查仅验证语法，不代表已经在当前线上页面完成运行或提交验证。
