# 南京晓庄 2026 学生手册自动作答助手

一个 JavaScript 用户脚本，适用于指定的问卷星学生手册页面。当前脚本版本为 **1.1.1**。

## 功能

- 在浏览器本地保存姓名、学号，刷新后先填写基本信息，再自动作答。
- 内置题库，按题干、题型及选项文本匹配答案，支持选项顺序变化。
- 未找到可用题库答案时，单选题随机选择一个选项，多选题选择全部选项。
- 浮窗显示题库命中、随机/全选及异常情况，支持暂停、继续和重填本页。
- 浮窗支持拖动、折叠。
- 不自动提交，检查结果后需自行提交。

## 安装与使用

1. 在浏览器安装 Tampermonkey 等兼容用户脚本的扩展。
2. 打开仓库中的 `南京晓庄2026学生手册自动作答助手.user.js`，点击 **Raw**，由用户脚本扩展完成安装；也可以新建脚本，粘贴完整代码后保存。
3. 打开脚本匹配的页面：<https://ks.wjx.com/vm/mHriy8I.aspx>。
4. 在右下角助手的“基本信息设置”中填写姓名、学号，点击“保存信息”。
5. 刷新网页，脚本将读取已保存信息并开始填写、作答。
6. 检查基本信息、随机/全选及异常详情，按需手动修改答案，最后自行提交。

修改基本信息后，也需要保存并刷新页面。已经处理的题目不会反复覆盖手动调整；点击“重填本页”会再次应用脚本的选择规则。

## 适用范围与数据

- 当前 `@match` 为 `https://ks.wjx.com/vm/mHriy8I.aspx*`，并非通用问卷脚本。
- 学院固定为 **信息工程学院、人工智能学院**，对应源码中的 `COLLEGE` 常量；若需适配其他学院，需要同时核对页面控件和学院选项。
- 姓名、学号保存在当前问卷页面所属站点的 `localStorage` 中，键为 `njxzc.handbook.profile.v1`。脚本没有额外的网络请求或数据上传逻辑；这些信息会被填写到问卷中。
- 内置题库包含待确认答案。随机单选及多选全选属于兜底选择，不能视作正确答案。
- 网页结构、选项或规则变化可能影响脚本运行。

